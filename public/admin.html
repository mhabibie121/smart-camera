Batas kotak grid

HikCentral (OpenAPI)

Untuk kamera dari server HikCentral pihak luar. URL RTSP-nya berisi token yang cepat kedaluwarsa, jadi sistem meminta URL baru otomatis setiap kali kamera ditonton. AppKey & AppSecret diminta dari pengelola HikCentral.

Tampilan tanpa login (monitor)

Halaman utama langsung menampilkan CCTV & View yang dibagikan, tanpa login. Login tetap dibutuhkan untuk menyimpan View, PTZ, dan admin. Cocok untuk PC/TV monitor di ruang kontrol.
⚠ Siapa pun yang bisa membuka alamat aplikasi ini (dan IP-nya diizinkan) bisa melihat kamera grup tersebut. Sebaiknya batasi ke IP PC monitor. Bagikan View dari tampilan live: arahkan ke View, klik ○ Bagikan.

Modul rekaman

Merekam kamera terpilih secara terus-menerus ke hardisk server, seperti NVR. Video disimpan apa adanya (tanpa encode ulang). Kalau hardisk hampir penuh, rekaman paling lama dihapus otomatis.
Sebaiknya hardisk terpisah khusus rekaman, mis. D:\CCTV-Rekaman. Pakai hardisk surveillance (WD Purple / SkyHawk).

Restore dari backup

Pilih file backup .json. Data di backup akan ditambahkan / diperbarui; data yang tidak ada di backup tidak dihapus. Sebelum restore, data sekarang otomatis disalin ke folder data\backup. Untuk file CSV kamera, pakai tombol Import CSV di tab Kamera.

Kamera

URL RTSP diminta otomatis ke HikCentral setiap kali kamera ditonton. Atur server & AppKey di Pengaturan.
Kalau URL tidak berisi user:pass, login default dari Pengaturan yang dipakai. Password yang tersimpan ditampilkan sebagai ***; biarkan saja kalau tidak ingin mengubahnya.
Kosongkan untuk memakai login default dari Pengaturan.

Import kamera dari CSV

Kolom: nama, lokasi, ip, port, channel, username, password, rtsp, rtsp_sub, grup (opsional: ptz isi 1 untuk kamera PTZ, http_port default 80). port = port RTSP, biasanya 554. Wajib nama, lalu ip (mode Dahua) atau rtsp berisi URL RTSP lengkap. Grup boleh lebih dari satu, pisahkan dengan |. Pemisah koma atau titik koma (Excel) dua-duanya bisa. Kamera dengan IP+port+channel yang sama akan di-update.

Tambah NVR (semua channel sekaligus)

Isi alamat & login NVR Dahua, lalu klik Baca channel. Nama kamera diambil langsung dari NVR. Setiap channel yang dicentang menjadi satu kamera.
