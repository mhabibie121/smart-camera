Sambung lewat P2P Dahua (SN) eksperimen
Lewat cloud Easy4IP Dahua memakai dh-p2p. Fitur P2P di perangkat harus aktif (Network → P2P). Mode Relay lewat server Dahua (lebih lambat, tapi paling sering berhasil). Mode Python hanya 1 koneksi sekaligus. Bisa putus sewaktu-waktu. Hanya bisa dipakai dari PC yang menjalankan halaman ini.
Failover otomatis IP → P2P (radio putus) eksperimen
Kamera ditonton lewat IP (jalur radio). Kalau IP tidak terjangkau lebih dari batas waktu, stream otomatis pindah ke P2P lewat SN, lalu kembali ke IP setelah IP stabil lagi. Kamera muncul di grid dengan nama yang sama dan pemutar menyambung ulang sendiri. Data hanya disimpan selama halaman tes jalan.
